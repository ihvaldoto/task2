# Практическая работа № 2. Вариант 4

## Сборка и запуск

Для сборки нужны JDK 21 и Maven. Для запуска готового JAR достаточно Java 21 или новее.

```sh
mvn clean package
java -jar target/NauJava-1.0.jar
```

При запуске без аргументов открывается меню. Номер задания можно передать сразу.

| Задание | Что делает | Команда |
| --- | --- | --- |
| 1 | Генерирует массив целых чисел и ищет последний положительный элемент | `java -jar target/NauJava-1.0.jar 1 10` |
| 2 | Генерирует список вещественных чисел и сортирует его выбором по возрастанию | `java -jar target/NauJava-1.0.jar 2 10` |
| 3 | Преобразует список сотрудников в строки вида «Имя - Отдел» через Stream API | `java -jar target/NauJava-1.0.jar 3` |
| 4 | Делает GET-запрос к httpbin.org и выводит значение `headers.Accept` из JSON | `java -jar target/NauJava-1.0.jar 4` |
| 5 | Обрабатывает строки из очереди в порядке поступления | `java -jar target/NauJava-1.0.jar 5` |

В заданиях 1 и 2 второй аргумент задаёт размер массива или списка. Если размер не указан, программа запросит его. Допустим размер 0.

Для задания 4 нужен доступ к [httpbin.org](https://httpbin.org/anything). Библиотека Gson включена в JAR.

В задании 5 вводите данные по одной строке. Пустая строка или конец ввода завершает задание после обработки очереди.
